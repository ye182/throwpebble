# Aimu 日记森林 · UI 契约（最新定稿）

仅描述**当前最终版**行为。历史迭代说明不再保留。AI 侧同内容见 `.cursor/rules/ui-hard-lessons.mdc`。

## 开场 / 登录

| 项 | 定稿 |
|----|------|
| 地面 | 粉色 splash 即页面地面；上下铺满；左右可留极窄白边 |
| 键盘 | overlay，不压缩 stage / 表单；`lockEntryViewport` + `interactive-widget=overlays-content` |
| 登录按钮 | 明确 `width` + `appearance: none`（防 WebKit 收缩） |
| 桌面框 | 仅 `min-width: 769px` 且 `pointer: fine` 时居中手机框 |

## 日记主壳

| 项 | 定稿 |
|----|------|
| 高度锁 | `--app-h` 锁定；键盘打开时 stage / 黄区 / 底栏不跟着变矮或被顶飞 |
| 滚动 | focus / visualViewport 时 `scrollTo(0,0)`，禁止布局 pan |

## 心情底装饰

| 项 | 定稿 |
|----|------|
| 组成 | 左猫 + 扁椭圆轨道（三图标分相）+ 右猫，**整组**移动 |
| 尺寸 | 右猫 160px；左猫与轨道参照 `160/3`；未经要求勿改尺寸 |
| 位置 | JS 将 cluster 放在卡片底与底栏顶的中点间隙 |
| 气泡 | 水平固定 `left: 88%` / `right: 58%`（`58%` 为自 `72%` 右移后的定稿）；只改垂直除非用户明确要求左右 |

## 全屏阅读

| 项 | 定稿 |
|----|------|
| 挂载 | `createPortal(..., document.body)` |
| 返回 | 全屏层自带顶部「← 返回」，关闭全屏（含收藏消息全屏） |

## 黄区收藏

| 项 | 定稿 |
|----|------|
| 列表保留 | 拖藏后黄区出现副本；下方会话列表**仍保留**原消息（不移出） |
| 预览条数 | 黄区预览最多展示最近 **1** 条收藏；超出显示「还有 N 条收藏」，点开全屏见全部 |
| 幂等 | 同一条已收藏再拖不重复追加 |
| 每条收藏 | 自包含块：正文 → 该条记录时间（块内右下、文档流）→ 黄线分隔；一条消息对应一条时间，禁止「先堆消息再堆时间」 |
| 定位 | 收藏时间在 `.pinned-reply-meta` 内 `text-align: right` + `.record-stamp`（`position: static`）；禁止相对黄区 `absolute; bottom` |
| 日记「记录于」 | 紧跟日记正文下方、收藏列表上方（`.record-stamp--after-body`）；不绝对钉在黄区右下角 |
| 字号 | 所有记录时间统一 `0.75rem` / `line-height: 1.35` |
