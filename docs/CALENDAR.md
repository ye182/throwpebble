# 三、日历墙（定稿）

**嵌入说明**：项目三（日历墙）内容嵌在本仓库（项目二）内，融合方案 A——底栏并行 Tab，顺序 **小屋 → 日历**。勿拆成独立项目三仓库/目录。里程碑摘要见 `docs/PROJECT3.md`。

**产品顺序**：本章（项目三 / 日历墙）接在项目二日记壳（小屋）之后——底栏下一 Tab「日历」。讨论结论与视觉契约写于此；实现见 `src/components/calendar/`。

## 视图

| 视图 | 行为 |
|------|------|
| **月**（默认） | 对齐参考图：大号月份数字 + 英文缩写、右侧插画、Mon–Sun 网格 |
| **年** | 当年 12 个月缩略；该月任一日有情绪记录则示意红点 |
| **日** | 打开所选日期：有记录时右侧插画下 muted 条数提示 + 最多 2 条预览（早→晚）；无则仅空态文案（无「去记录」CTA） |

切换控件：年 | 月 | 日；月/年可用左右翻页。

## 月视排版

- 白底；左大号 `MM`，其下英文月缩写（如 `Mar.`）
- 右：治愈系小猫水面插画（`calendar-companion.png`，已裁白边）；Header 右栏展示框尺寸与原先一致（`height: clamp(88px, 18vh, 120px)` + `object-fit: contain`），勿因换图改布局
- 内容列：`.calendar-content` 全宽 + 左右 24px，勿再加 `--cal-content-max: 340px` 硬收缩
- 模块背景透明，沿用 AppShell `stage-map` 与产品 ink/muted/accent
- 无网格框、无卡片阴影、无系统日历按钮风
- 表头：`Mon`–`Fri` 低对比；`Sat`/`Sun` 产品暖强调色
- 一周从**周一**起算
- 单元格：公历数字 + 下方小字（节日名优先，否则农历日）；大量留白
- 情绪日 / 选中：不规则**手绘红圈** SVG（禁止 `border-radius: 50%` 实心圆）

## 情绪标记

- 当日有 ≥1 条情绪/日记记录 → **手绘红圈**（不规则 SVG 描边，非实心圆点、非完美几何圆）
- 无记录 → 不画圈
- 日期键：`YYYY-MM-DD`（本地）；小屋保存日记（**私密 / 探索**）都会写入
- 日详情存于 `aimu_mood_details_v1__u_<userId>`（登录后；遗留无后缀键会在 `bindMoodStorageToUser` 时安全迁入）。写入路径：`saveDiaryEntry` → `recordMoodDetail`：**按日存数组**，每条含 mood、全文 body、`visibilityMode`（私密/探索）、`entryId`、`createdAt`
- 旧版单对象按日 → 读时迁移为单元素数组，不丢记录；幂等更新按 **resolved** `entryId`（无存档 id 时用 `entry_day_${dateKey}_${createdAt|legacy}`），并回写 `entryId`
- **跨端同步**：已登录时保存会 `POST /api/diary/entries`；打开 App / 日历 Tab 时 `GET` 拉回并合并进**当前用户**本地日历（同一账号 iOS / Android 可见）；换账号不上传/不混用上一账号本地 blob


## 日视图

- **空态**：空文案带浅底；「去记录」在右上插画下方 → 小屋**心情卡片页**
- **有记录**：左上大号为当日日号 DD，下方 `Aug. 2026`；右上插画下条数与「继续记录」**左缘对齐**；「继续记录」→ 跳过选卡，直接进**写正文页**，心情取当日**最新一条**的 mood（无则回退第一张「晴天」）；换心情请回首页走完整选卡流程
- 选卡流程与「继续记录」捷径保存后都会写入日历；返回回到该日视图
- 日预览按 `createdAt` **早→晚**排列；连续相同 mood **只显示一次**「心情：…」标题，多条正文归在该标题下（左滑该正文行可「修改 / 删除」）
- 每条正文可点 → 打开该条对应的私密/探索预览；左滑「修改」→ 写正文页预填并按 `entryId` 原地更新；「删除」→ 本地当前用户 mood details（已登录则 `DELETE /api/diary/entries/:id`）
- 「还有 M 条」可点 → 展开当日全部记录；列表过长时在日历模块内继续上滑查看
- 从日视图进预览后点返回 → **回到该日视图**（通用：有上一页回上一页，否则回小屋首页）
- 日视图不展示「M月D日 / 农历」行；保留 header 左日期 + 右插画
- 切回日历 Tab / 进入日视图 / 窗口 focus·visibility / `storage` / `aimu-mood-updated` 时会 `moodTick` 重读；并拉取服务端日记合并，避免探索保存后或跨设备看不到记录

## 点选

- **月视图**：点任意日期 → 进入该日的日视图
- 顶栏切到「日」：同上，针对当前所选日期
- **预览行**：切到小屋 Tab，打开该条日记**预览**（`comments` 步）
  - 保存时为**私密模式** → 私密预览
  - 保存时为**探索模式** → 探索预览（并拉取开场角色回复）
  - 预览内可进/出全屏，交互与正常日记流一致
  - 旧数据若缺 `visibilityMode` / 全文：缺 mode 默认探索；正文优先 `body`，否则回退 `bodyPreview`
